One sentence about the best meal ever had: beef noodles in a Taipei alley at 2 a.m., star-anise steam fogging my glasses — the bar no restaurant meal since has cleared.

## Run it

```sh
node main.ts
```

The program writes the sentence to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
